# 소스 분석 및 수정 기록

대상: 제공된 `3d-2.html` → Compass v1.0.1 공개본.

## 종합 판단

3D 디자인과 방향 학습 게임은 활용할 수 있습니다.
실제 나침반으로 공개하기에는 방향 데이터의 출처와 권한 처리에서 수정이 필요했습니다.
해당 로직을 수정하고, 디자인·미션·테마는 유지했습니다.

| 발견한 문제 | 영향 | 반영 사항 |
| --- | --- | --- |
| `absolute=false`인 상대 회전도 방위로 사용 | 기기 시작 자세를 북쪽으로 오인할 수 있음 | 절대방위 또는 iOS 나침반 값만 수용 |
| 지역과 무관한 -8.5° 및 사인 함수 편각 | 근거 없는 오차를 추가하며 진북이라고 표시 | 임의 보정 제거, 기준 방위 안내 |

## 자동 검증

`node --test tests/*.cjs`: 8개 통과.

1. 수평 세로 상태의 기본 네 방위.
2. 화면 회전·기울기 투영·0/360° 경계.
3. 상대 회전·결측값·수직 자세 제외.
4. 요청 전 미구독 및 취소 후 뒤늦은 센서 이벤트 무시.
5. GPS 좌표가 방위에 영향을 주지 않음, 중지 후 지연 좌표 무시.
6. 취소 후 도착한 iOS 권한 허용으로 추적이 다시 시작되지 않음.
7. 센서 스트림 중 설정창을 열어도 즉시 닫히지 않음.
8. WebGL 생성 실패 조건에서 앱 전체 초기화와 첫 프레임 실행.

JavaScript 구문, DOM ID 및 로컬 자산 경로, CSS 생성도 확인했습니다.

## 검증의 한계

공개 주소에서 데스크톱 2D 호환 화면·동쪽 90° 전환·테마 변경·미션 목표 조준 및 발견 1/8 처리를 확인했습니다.
확인 브라우저가 WebGL을 지원하지 않아 3D 렌더링·모바일 화면·물리 센서는 별도 확인이 필요합니다.
권한 검증은 모의 브라우저 객체를 이용한 로직 검사입니다.
실제 Android/iOS 권한 UI 및 자기장 정확도까지 증명하지 않습니다.
공개 저장소 생성·업로드·Pages 최초 배포를 완료했습니다.
확인 브라우저에서 WebGL 미지원이 발견되어 v1.0.1에 Canvas 2D 호환 렌더러를 추가했습니다.

## v1.1.0 화면 간소화

- 상단에 소개·센서·소리·전체화면·탐험 메뉴를 작은 도구 모음으로 배치했습니다.
- 기본 화면의 수호신·도감·슬라이더·방위 버튼·테마·자동 탐험 카드를 제거하고 메뉴 안으로 옮겼습니다.
- 하단은 현재 방위각·방위명·간단한 센서 상태만 표시합니다.
- 미션은 시작할 때만 표시하고 종료 시 감춥니다. 나침반 공간도 다시 확보합니다.
- 앱 시작 시 센서 팝업을 띄우지 않습니다. 센서 연결은 사용자가 선택합니다.
- 카메라가 화면의 짧은 축에 맞춰 나침반을 크게 담도록 수정했습니다.
- 360×740, 393×852 크기의 브라우저 프레임에서 기본 배치·메뉴·미션 시작과 종료·나침반 공간 복구를 확인했습니다.
- 393×852 기본 화면에서 캔버스는 약 667px 높이를 사용하며 도감·미션·수동 조작 카드는 기본적으로 보이지 않습니다.
- 센서 계산과 권한 처리 회귀 검증 8개는 통과했습니다. 실제 자기장 센서와 3D 렌더링은 이번 브라우저에서 검증하지 못했습니다.

## v1.1.1 디자인 설정

나침반 디자인 선택은 탐험 메뉴의 설정 아래로 분리했습니다. 기존 3개 유물 테마를 선택할 수 있고, 선택값은 로컬 저장소에 보존합니다. 저장소가 제한된 환경에서도 앱 사용과 디자인 변경은 계속 가능하며 다음 방문 시 보존은 보장하지 않습니다.
